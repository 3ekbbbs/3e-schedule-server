识别结果

三分钟上手

  1. 配地图 Key（只做一次）：把腾讯位置服务的 Key 粘进去就行。 同一个 Key 勾了 JavaScript API GL 就能用；没勾的话去 lbs.qq.com 控制台补一下。
  2. 把地图拖到你的学校（缩放调到看得见楼）。 下次打开会**回到你上次看的地方**，不用每次重拉。
  3. 点左上那个大按钮「从 OSM 导入这一带的建筑」 —— 最省事的做法。一次能把整片校区的真实轮廓和名字拉下来 （数据来自 OpenStreetMap，ODbL 协议，可免费使用，需署名）。
  4. OSM 上没有的楼，点地图补：在地图上单击那栋楼， 它会自动建一条，并自动去找那栋楼的真实轮廓 —— 你不用描。名字如果腾讯地图上有也会自动填上。
  5. 改名字 / 选分类：在右边填楼名（如「明德楼B1」）、 填别名（如「明德B1，B1」，用逗号分隔），再用色块选个类别 （教学楼 / 宿舍 / 食堂…）。手机上按类别筛选就靠它。
  6. 轮廓不对？左边有「自动补上真实轮廓」—— 把那些还是默认矩形的楼一次换成真形状。
    真要自己描，用右边「开始描轮廓」，然后沿着外墙点一圈。
  7. 标每层房间（可选）：右边「楼层与房间」→「＋ 加一层」， 在方格图上拖一个框就是一间房。方格代表这栋楼， 正中央是楼的中心。只标「大概在哪」就够用。
  8. 填包信息：左边最下面「数据包信息」点开 —— 包标识（它同时是用户的授权码）、名称、说明。
  9. 一键发布：点右上角「一键发布」→ 用管理员账号登一次 → 发出去，界面上会给你那串授权码，直接转发给要用的人。
    只是想把文件给别人？用「导出文件」。
    ⚠️ 「导出（含 Key）」= 这份壳里带着腾讯 Key 的明文， 只在确认只发给该发的人时用。

分类和分层是后加的字段，格式版本因此从 1 升到了 2。 老包（版本 1）照样能导进来，只是没有分类和房间。
